# Sprint Dashboard Practice

Personal practice repo for learning how GitHub works and how to build a simple sprint dashboard.

**Data:** all data here is synthetic. No work or client data.

## Files

- `sample_rally_export.xlsx`: a mock export with the same column layout as a Rally story export. Three sheets: Stories, Iterations, Data Dictionary.
- `generate_sample_export.py`: recreates the sample file. Run with `python3 generate_sample_export.py` (needs `pip3 install openpyxl`).

## Plan

- Cycle 1: GitHub basics (this step)
- Cycle 2: publish a static page with GitHub Pages
- Cycle 3: build the dashboard from the Excel file
- Cycle 4: make it reusable as a template
